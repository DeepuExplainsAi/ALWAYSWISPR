## Wispr v4.1.1

- **Updates fixed:** "Update available" now shows only when GitHub really has a newer APK. If your phone already runs the latest APK you see "✓ You're on the latest version".
- **Check now** in Settings → Updates always asks GitHub fresh. A separate orange **Update** button appears only when a real update exists, and every check shows a short message.
- **Mini window (hold the bubble):** smaller by default, drag the orange corner to resize it, drag the bar on top to move it, double-tap the bar to reset. The size button in the header switches Small / Medium / Large.
- **You can see what you type or say:** the window moves above the keyboard, and spoken text lands in the chat box so you can check it before sending (with a live "Listening… 0:05" timer).
